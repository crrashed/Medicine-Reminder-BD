# Medicine Reminder BD V2
Upload all files to the root of your GitHub repository and replace the old files. Then GitHub Pages will rebuild the site.

V2 includes medicine schedule, stock/low-stock warning, taken/skipped history, progress, family members, doctors, prescription file selection, profile, export backup, notifications and PWA support.

Data is stored locally in the browser in this starter version. For production, add secure authentication, cloud database/storage and server-side notification infrastructure.
