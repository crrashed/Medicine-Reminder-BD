# Medicine Reminder BD

A simple Bangladesh-focused medicine reminder PWA built with HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser. For full PWA/service-worker support, use a local server such as VS Code Live Server.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and open the generated Pages URL.

## Notes
- Medicine data is stored in the browser's localStorage in this starter version.
- Browser notification permission is required for reminders.
- For real multi-user accounts, cloud backup, secure prescription storage, SMS/WhatsApp reminders, and payments, add a backend such as Firebase or Supabase.
- This app does not diagnose, prescribe, or change medication doses.
